# TypeScript Development Workspace

Small TypeScript learning scripts, grouped by language topic. Each directory under `TypescriptLearning` is a set of standalone files you can run with Node after installing TypeScript.

Author: bikash-backendcraftsman

## Layout

- `TypescriptLearning/Typescript_Variable` — `let`, `const`, and primitive types
- `TypescriptLearning/Typescript_Function` — typed functions, arrows, optional and default parameters
- `TypescriptLearning/Typescript_Object` — object types and nested objects
- `TypescriptLearning/Typescript_Interface` — interfaces and extension
- `TypescriptLearning/Typescript_Array` — typed arrays
- `TypescriptLearning/Typescript_Tuple` — fixed-length tuples
- `TypescriptLearning/Typescript_Union` — union types
- `TypescriptLearning/Typescript_Narrowing` — narrowing with `typeof` and `in`
- `TypescriptLearning/Typescript_Literal` — literal types
- `TypescriptLearning/Typescript_Enum` — numeric and string enums
- `TypescriptLearning/Typescript_Generic` — generic functions and interfaces
- `TypescriptLearning/Typescript_Class` — classes and access modifiers
- `TypescriptLearning/Typescript_Type_Alias` — type aliases
- `TypescriptLearning/Typescript_Utility` — `Partial`, `Pick`, `Omit`, and `Record`
- `TypescriptLearning/Typescript_Async` — promises and `async` / `await`
- `TypescriptLearning/Typescript_Exercise` — practice session

## Run

```bash
npm install
npx tsc --noEmit
npx tsx TypescriptLearning/Typescript_Variable/primitiveTypes.ts
```
